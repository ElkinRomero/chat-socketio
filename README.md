# Chat en tiempo real con Socket.IO

Aplicación de chat con Node.js (módulo `http`) y Socket.IO.

## Ejecutar
```bash
npm install
npm start
```
Abre http://localhost:3000 en varias pestañas o navegadores y escribe un nombre distinto en cada una.

## Estructura
- `server.js`: servidor HTTP + Socket.IO
- `public/index.html`, `public/client.js`, `public/style.css`: cliente
